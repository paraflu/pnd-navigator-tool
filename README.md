# PND Navigator Tool

Strumento web per modificare il file PNDNavigator dei navigatori GPS Renault.

## Procedura

1. Scarica e installa HxD (editor esadecimale)
2. Carica il file PNDNavigator
3. Trova l'indirizzo x00402920
4. Sostituisci il byte D6 con B9
5. Salva il file modificato nella root della scheda SD
6. Inserisci la scheda SD nel navigatore GPS

## Deploy

Questo progetto è pubblicato su GitLab Pages.

## Avvertenze

⚠️ Modifica il file a tuo rischio. Assicurati di avere un backup del file originale.
